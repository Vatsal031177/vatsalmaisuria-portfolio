# Vatsal Maisuria - Portfolio Website

A modern, professional portfolio website built with HTML5, Tailwind CSS, and Vanilla JavaScript.

## Features
- **Responsive Design**: Mobile-first approach using Tailwind CSS.
- **Admin Inbox**: Private message management using browser LocalStorage.
- **CV & Cover Letter**: Downloadable documents section.
- **Smooth Animations**: Interactive UI with Lucide icons.

## Project Structure
- `index.html`: Main portfolio page.
- `admin.html`: Message management dashboard.
- `static/uploads/`: Directory for CV and Cover Letter PDF files.

## How to Run
Simply open `index.html` in any modern web browser or use a local server like:
```bash
python -m http.server 8000
```

## Admin Access
To view messages sent through the contact form, go to `admin.html`.
